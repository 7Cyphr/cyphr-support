# CYPHR Support

This repository is the place to report bugs, issues, and concerns related to CYPHR.

## Before opening an issue

- Search existing issues to see if your problem has already been reported.
- Do not include API keys, credentials, tokens, or other sensitive information in an issue.
- For security-related concerns, avoid publicly sharing details that could put other users at risk.

## Reporting an issue

When reporting a problem, please include enough information to reproduce or understand it, such as:

- What happened
- What you expected to happen
- Steps to reproduce the issue
- Browser or environment, if relevant
- Any relevant error messages
